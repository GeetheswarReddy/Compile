# Ticket T08: Reflection Recording API

## Context Digest

Reflection audio is private to learner/question, with one recording at a time. Metadata is in DynamoDB, binary audio is S3 with 30-day lifecycle expiration; deletion is immediate and replacement requires confirmed deletion. Complete digest: `tickets/digest.md`.

## Upstream interfaces

T01 reflection contracts; T02 `ReflectionRepository`.

## Ticket

Depends on: T01, T02

Files owned: `backend/reflection.py`, `tests/test_reflection.py`

Interfaces consumed: T01 recording contracts; T02 repository; S3 upload/delete operations.

Interfaces produced: `create_reflection(event, context)` and `delete_reflection(event, context)` Lambda handlers.

Task: Issue upload metadata, enforce confirmed replacement, record expiry, and delete metadata/audio.

Acceptance criteria: Tests reject unconfirmed replacement, accept confirmed replacement, and validate delete behavior.

## Rules

- Do not create S3 buckets or lifecycle configuration; T09 owns infrastructure.
