# Ticket T10: Frontend Foundation and API Client

## Context Digest

Compile is an AWS-hosted React/Vite SPA with no SSR. Browser-generated UUID identity is persisted in `localStorage` and sent as `X-Learner-Id` to every API Gateway `/v1` request; there are no accounts, sessions, or auth flows. The UI must retain demo-learning content while execution/generation controls become read-only. Demo Trace is feature-flagged for demo mode only. See `tickets/digest.md` for the canonical, complete digest.

## Ticket

Depends on: none

Files owned: `frontend/package.json`, `frontend/vite.config.js`, `frontend/index.html`, `frontend/src/main.jsx`, `frontend/src/api/client.js`, `frontend/src/identity/learnerId.js`, `frontend/src/styles/global.css`

Interfaces consumed: `/v1` routes and the `X-Learner-Id` contract from the Context Digest.

Interfaces produced: `apiClient`; `getLearnerId() -> string`; Vite application bootstrap.

Task: Create the React/Vite foundation, persist browser UUID in localStorage, attach it to each request, and provide API-call wrappers.

Acceptance criteria:

- Frontend builds successfully.
- The client sends a stable `X-Learner-Id`.
- No authentication flow exists.

## Rules

- Edit only the owned files.
- Do not add SSR or authentication.
- Keep API wrappers aligned with the published `/v1` contract.
- Do not compose feature screens; T15 owns application composition.
