## Implementation notes

- Selected CodeMirror 6 over Monaco because it supplies the required editing primitives with a substantially smaller runtime and no worker configuration. The component uses direct CodeMirror modules instead of a React wrapper: `@codemirror/state`, `@codemirror/view`, `@codemirror/commands`, `@codemirror/language`, `@codemirror/lang-python`, and `@lezer/highlight`.
- Python syntax highlighting, line numbers, current-line highlighting, matching brackets, four-space indentation, undo/redo, an inner horizontal/vertical scroller, visible focus, and a compact Python label are enabled. There is no editor-level execution command or submit shortcut.
- All editor code is bundled by Vite. The production output contains only the existing HTML entry plus local JavaScript and CSS assets; there are no CDN requests, worker files, or runtime asset paths for the editor.
- The first CodeMirror/Python test exposed that the stock Enter command does not indent an incomplete block ending in `:`. The editor therefore supplies a focused Enter binding that handles Python block indentation while leaving Tab available for focus navigation.
