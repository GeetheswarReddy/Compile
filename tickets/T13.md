# Ticket T13: Hints, Reflection, and Consent UI

## Context Digest

Hints are requested one level at a time and never auto-advance. Reflection Recording is private browser audio, one per learner/question, with first-use consent, immediate delete, and explicit confirmed-delete-before-replace. Complete digest: `tickets/digest.md`.

## Upstream interfaces

T10 provides `apiClient`; T08 supplies `POST /v1/reflection` and `DELETE /v1/reflection/{questionId}`. Hint API is `POST /v1/hint` with `{ questionId, currentLevel }`.
