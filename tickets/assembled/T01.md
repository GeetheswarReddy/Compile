# Compile — Context Digest

Compile is a deployed AWS demo for adaptive Python placement practice. React/Vite is hosted on Amplify; API Gateway REST `/v1` invokes Python 3.12 Lambdas. Browser `localStorage` UUID is sent as `X-Learner-Id`; no accounts/auth. DynamoDB persists learner, Mastery, Question, Attempt, Trace, Reflection metadata, and separate learner/topic Prepared Questions; S3 retains reflection audio 30 days. Only `execution_runner` executes untrusted Python, in a subprocess with five-second timeout and 128 MB address-space cap. Topics are Arrays, Strings, Hash Maps/Two Pointers; scores are 1–10. First Run & Check alone changes Mastery by clamped +/-1; verdicts expose at most two failed cases and no hidden tests/reference code. Complete domain/API requirements follow `tickets/digest.md` exactly.

# Ticket T01: Shared Backend Contracts

Depends on: none

Files owned: `backend/contracts.py`, `backend/__init__.py`, `tests/test_contracts.py`

Interfaces consumed: Context Digest domain rules.

Interfaces produced: `Topic`, `Provenance`, `Question`, `SubmissionVerdict`, `LearnerState`, `MasteryState`, `PreparedQuestion`, `HintLevel`, and public API payload serialization helpers.

Task: Define frozen, validated Python domain types and API payload serializers shared by every backend Lambda. Encode Topic values, Difficulty Score 1–10, four Hint levels, and the maximum-two-failure Verdict rule.

Verification environment: `.venv` is available in the workspace. Run focused tests with `.venv/bin/python -m pytest tests/test_contracts.py`; do not use bare `pytest`.

Acceptance criteria:

- Tests reject invalid scores and Topics.
- Tests serialize all public API payloads without Hidden Tests or reference solutions.
- Exported interfaces match the names listed above.

# Hard rules

3. Flag every new interface at end under “New interfaces introduced.”
4. Report actual produced signatures at end.
5. Do not run or modify tests/files belonging to another ticket.
