# Compile — Context Digest

Compile is a deployed AWS demo for adaptive Python placement practice. React/Vite is hosted on Amplify; API Gateway REST `/v1` invokes Python 3.12 Lambdas. Browser `localStorage` UUID is sent as `X-Learner-Id`; no accounts/auth. DynamoDB persists learner, Mastery, Question, Attempt, Trace, Reflection metadata, and separate learner/topic Prepared Questions; S3 retains reflection audio 30 days. Only `execution_runner` executes untrusted Python, in a subprocess with five-second timeout and 128 MB address-space cap. Topics are Arrays, Strings, Hash Maps/Two Pointers; scores are 1–10. First Run & Check alone changes Mastery by clamped +/-1; verdicts expose at most two failed cases and no hidden tests/reference code. Complete domain/API requirements follow `tickets/digest.md` exactly.
