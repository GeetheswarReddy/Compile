# Ticket T18: Replace placeholder styling with a cohesive coding interface

Priority: P1
Status: Ready after T17 shared-file edits
Depends on: T17

## Evidence and direction

Use repository `image.png` as the before image. It shows a huge centered heading, default gray buttons, excessive empty space, and weak navigation hierarchy. `global.css` applies centered grid placement to the whole app and an h1 size up to 5rem. The requested direction is a compact LeetCode-like coding workspace with Compile branding.

## Files owned

`frontend/src/styles/global.css`, `frontend/src/App.jsx`, `frontend/src/baseline/baseline.css`, `frontend/src/hints/HintLadder.jsx`, `frontend/src/reflection/reflection.css`, `tickets/out/T18.md`.

## Interfaces consumed / produced

Consume existing App routing and feature component contracts. Produce shared CSS tokens for backgrounds, surfaces, borders, text, accent, spacing, typography, focus, and control states; document actual token names for T19/T20. No API changes.

## Work

- Replace global centered hero styling with a compact top navigation and full-width content area. Scope home-page typography so it cannot override baseline/workspace headings.
- Use a consistent dark neutral palette, restrained accent, readable text, subtle panel borders, and small radii. Style all primary/secondary buttons, inputs, badges, alerts, focus states, and disabled states.
- Present the three topics as deliberate cards with compact headings and clear baseline progress/action. Retain baseline gating and topic navigation.
- Harmonize baseline, hints, reflection, examples, and history with the same design; remove pale surfaces with unreadable inherited text.
- Keep supporting copy brief, and avoid a marketing hero on the coding screen.

## Acceptance criteria

- Before/after screenshots cover home and baseline at 1440×900 and 390×844; no default unstyled action buttons, clipped text, or horizontal page overflow.
- Heading scale is restrained (home title approximately 28–36px desktop), body copy readable, controls consistent, and keyboard focus clearly visible.
- Normal text contrast meets 4.5:1, controls have accessible names, and status is not conveyed by color alone.
- App routing, baseline gating, hints, and recording controls retain their behavior; build and relevant mounted tests pass.
- No final completion claim without visual inspection of rendered pages.
