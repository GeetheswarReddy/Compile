# Ticket T20: Upgrade the Python editing experience

Priority: P1
Status: Ready after workspace integration
Depends on: T18, T19

## Evidence and scope

CodeEditor currently renders a plain textarea. Provide a usable coding editor inside T19's right pane, retaining Compile's Python-only execution model.

## Files owned

`frontend/src/practice/CodeEditor.jsx`, `frontend/src/practice/editor.css`, `frontend/package.json`, `frontend/package-lock.json`, `frontend/test/editor.test.js`, `tickets/out/T20.md`.

## Interfaces consumed / produced

Retain `<CodeEditor value={string} onChange={function} readOnly={boolean} disabled={boolean} />`. Consume pane dimensions and T18 tokens. No submission, hook, or API contract changes.

## Work and acceptance criteria

- Use an established editor such as CodeMirror or Monaco, selected after checking package compatibility and bundle impact. Bundle required assets/workers locally; opening the editor must not require a third-party CDN.
- Supply Python syntax highlighting, line numbers, indentation, bracket matching, undo/redo, visible focus, and a compact Python label.
- Controlled value and onChange work with existing baseline/practice state: initialize from starter code, preserve edits across re-renders and errors, and replace content only when the owning flow changes questions or explicitly resets it.
- Fit the right pane without overflowing the document. Long code scrolls within the editor and remains usable at mobile widths.
- Keyboard users can enter and leave the editor; document the editor's tab-focus behavior. Provide an accessible label and retain read-only/disabled behavior.
- Do not introduce a second execution action, change scoring, or silently bind a keyboard shortcut that causes duplicate submissions.
- Tests cover typing/controlled updates, indentation, question value replacement, and read-only behavior; production build succeeds and editor works on Amplify without missing assets or worker errors.
- Record before/after production bundle size and verify editor loading does not obstruct question reading or lose code.
