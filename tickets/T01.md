# Ticket T01: Shared Backend Contracts

## Context Digest

Compile is an AWS-hosted React/Vite and Python 3.12 Lambda demo. All requests use `X-Learner-Id`, with no authentication. DynamoDB persists state; only `execution_runner` executes code. Questions are Python-only, Topics are Arrays, Strings, and Hash Maps/Two Pointers, and Difficulty/Mastery are integers 1–10. The first Run & Check alone changes Mastery by a clamped point; Verdicts expose at most two failures and never expose Hidden Tests or reference solutions. See `tickets/digest.md` for the canonical, complete digest.

## Ticket

Acceptance criteria:

- Tests serialize all public API payloads without Hidden Tests or reference solutions.
- Exported interfaces match the names listed above.
