# Ticket T04: Execution Service

## Context Digest

`execution_runner` is Compile's only untrusted-code executor. It runs Python code as a subprocess with a five-second wall-clock limit, 128 MB `setrlimit` address-space limit, 256 MB Lambda configuration, and no outbound network permissions. Verdicts provide pass/fail and no more than two failure details. Complete digest: `tickets/digest.md`.

## Upstream interfaces

T01 exports `Question` and `SubmissionVerdict`.

## Ticket

Depends on: T01

Files owned: `backend/execution_runner.py`, `tests/test_execution_runner.py`

Interfaces consumed: T01 `Question`, `SubmissionVerdict`; execution constraints in Digest.

Interfaces produced: `run_submission(question: Question, code: str) -> SubmissionVerdict`; `verify_question(question: Question) -> bool`.

Task: Implement subprocess isolation, timeout, address-space cap, and failure redaction.

Acceptance criteria: Tests cover passing, failing, infinite-loop, memory-heavy submissions and prove at most two failures return.

## Rules

- Edit only owned files.
- Do not execute code in any other module or use an external judge.
